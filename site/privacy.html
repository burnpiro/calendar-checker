Privacy policy

Effective November 3, 2026 · Calendar Checker v0.6.0

Calendar Checker is an open-source Chrome extension that connects directly to Google Calendar. It has no application backend and does not send your calendar information to the developer.

Google account access

You explicitly authorize each Google account. The extension requests identity/email information, access to the account's calendar list, permission to read and edit events, and access to available free/busy information. It does not read Gmail messages or discover accounts by scraping cookies.

Google OAuth and Calendar API requests go directly to Google. When you save an event with guests or a video-conference request, that information is sent to Google to carry out the requested event change. Invitation delivery and meeting creation are handled by Google.

Information stored locally

  • Account identifiers, email addresses, calendar lists and validated preferences.
  • Cached events, availability periods, sync state and pending offline changes.
  • Reminder delivery history, snoozes and imported notification sound files.
  • Sanitized diagnostics that exclude OAuth tokens, event contents, account emails and calendar identifiers.

Preferences use chrome.storage.local. Event data, pending changes and sound files use local IndexedDB. Preferences are not synchronized through Chrome's cloud storage.

Authentication

Native-account access tokens are managed by Chrome. Tokens for the optional account chooser are held in the extension worker's memory. The application does not persist these access tokens or collect client secrets. Google's and Chrome's own account/session handling remains subject to their policies.

Notifications

Optional desktop notifications can show event information through Chrome and your operating system. Notification privacy settings let you limit the displayed detail. Custom sound files remain local and are not uploaded. Per-event Google notifications are managed separately by Google.

Telemetry and sharing

The extension contains no analytics, advertising or telemetry and does not sell user data. Data is sent to Google only for the authorized account and calendar operations. If you manually share a diagnostic report or submit a GitHub issue, review what you include.

Control and deletion

You can pause accounts, choose visible calendars, disable reminders and remove accounts. Account removal clears its local cached data after pending changes are resolved. Removing an account locally does not revoke Google's app consent or sign you out of Gmail; consent can be revoked in your Google Account settings.

Uninstalling the extension clears its local Chrome-profile storage, including unsynced changes and imported sounds. An uninstall does not delete events already saved in Google Calendar.

This website

This is a static GitHub Pages site. It has no forms, tracking scripts, analytics or application cookies. Images and scripts load from the same site. GitHub processes ordinary hosting requests under the GitHub privacy statement. All screenshots use fictional accounts and events.

Questions

Open an issue in the project repository. Do not include passwords, tokens, OAuth callback URLs or private event data. The source code is available under GPL-3.0.
